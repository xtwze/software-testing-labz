# Лабораторная работа № 1 по тестированию ПО

Модульные тесты класса `EstimatePolicy`. Выполнен **второй вариант**.

Метод `minutes(int points)` переводит баллы трудоёмкости в минуты:

- один балл — 15 минут;
- допустимы значения от 1 до 8 включительно;
- для остальных значений выбрасывается `IllegalArgumentException` с сообщением `points must be between 1 and 8`.

## Тесты

В классе `EstimatePolicyTest` сохранены примеры занятия и добавлены задания второго варианта. Каждый сценарий проверяется отдельным методом.

| Источник | Вход | Ожидание |
| --- | --- | --- |
| Исходный пример | 1 | 15 минут |
| Исходный пример | 0 | Исключение и его сообщение |
| Разбор занятия | 2 | 30 минут |
| Разбор занятия | 9 | Исключение |
| Второй вариант | 4 | 60 минут |
| Второй вариант | 7 | 105 минут |
| Второй вариант | -2 | Исключение |
| Второй вариант | 11 | Исключение и его сообщение |

В первом задании второго варианта указаны и 45, и 60 минут для 4 баллов. В тесте используется 60, поскольку `4 * 15 = 60`.

## Запуск

Нужен JDK 25 или новее. Maven Wrapper входит в проект; при первом запуске требуется подключение к интернету.

```bash
cd 01
sh ./mvnw test
```

Windows PowerShell:

```powershell
cd 01
.\mvnw.cmd test
```

Запуск только тестового класса:

```bash
sh ./mvnw "-Dtest=EstimatePolicyTest" test
```

В IntelliJ IDEA нужно открыть папку `01` как Maven-проект и запустить `EstimatePolicyTest` зелёной кнопкой рядом с названием класса. Если при импорте через wrapper библиотеки не распознаются, выбрать для этого проекта встроенный Maven и повторить синхронизацию.

Версии из стартового проекта: Java release 25, JUnit 6.1.3, Maven Wrapper 3.10.0, Surefire 3.6.0.

## Эксперимент с ошибкой

Перед запуском прогнозируем: после удаления верхней границы тест `elevenPointsAreRejectedWithMessage` упадёт, потому что 11 попадёт в расчёт и метод вернёт 165 вместо исключения. Также упадёт пример для 9.

1. Запустить тесты с исходным условием `if (points < 1 || points > 8)`.
2. В `EstimatePolicy.java` временно заменить его на `if (points < 1)` и снова запустить тесты.
3. Восстановить обе границы и повторить запуск. Ожидания тестов не менять.

| Запуск | Tests run | Failures | Errors | Skipped |
| --- | ---: | ---: | ---: | ---: |
| Исходный код | 8 | 0 | 0 | 0 |
| Удалена верхняя граница | 8 | 2 | 0 | 0 |
| Код восстановлен | 8 | 0 | 0 | 0 |

Проверки для 9 и 11 во втором запуске сообщают: `Expected java.lang.IllegalArgumentException to be thrown, but nothing was thrown.`

Финальное состояние проекта: обе границы восстановлены, все 8 тестов проходят.
